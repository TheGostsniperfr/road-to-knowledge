# Vision

Road to Knowledge answers three questions for one person: what do I know, how well, and
where should I go next. It is a map first, a review tool second and an AI context
source third.

## Principles

1. **The map is the knowledge.** Galaxies, clusters and stars are the themes,
   sub-themes and subjects. Brightness is level. Light only appears where knowledge is.
2. **Nothing fades on its own.** A level never decreases automatically. Time only adds a
   discreet amber dot; the user decides what a forgotten subject is worth.
3. **Plain files in git.** One Markdown file per subject, readable without the app,
   diffable, private. The app is public, the knowledge is not.
4. **Agents read little and write nowhere important.** MCP tools return briefs and
   subtrees, never the whole graph. Writes go to the inbox or to a proposal branch.
5. **Beautiful and fast.** Procedural galaxies on the GPU, crisp at every zoom, no lag.

## Users and use

- Desktop, local, daily: open the map, review the cards due where you are zoomed, raise
  a level after a lab, capture an idea.
- Claude Code: ask "what do I know about container runtimes", let an agent draft a
  fiche on a proposal branch, triage the inbox in the evening.

## Not in V1

Mobile and the Claude mobile connector, news brief, semantic view from embeddings,
Anki import and export, book ingestion, discovery suggestions. See
[`ROADMAP.md`](ROADMAP.md).

The original design, with the visual exploration and the full feature audit, is the
"Road to Knowledge" artifact of 2026-11-08.
